# Forza Horizon 6 — AFK-бот

Бот по кругу выполняет сценарий из `config.toml`: держит газ и руль нужное
время, потом нажимает кнопки, чтобы пройти экраны результатов и запустить
заезд заново. Нажимает он через виртуальный геймпад Xbox или через клавиатуру.

- Пауза — **F8**, стоп — **F10**. Работают, даже когда активно окно игры.
- Если активно не окно игры (вы открыли браузер или Discord), бот отпускает
  все кнопки и ждёт, пока вы вернётесь в игру.
- Можно ограничить работу числом циклов или минут.

> Бот работает только на ПК с Windows 10/11. На Xbox напрямую он не запустится.
> Автоматизация может противоречить правилам игры, особенно в онлайн-режимах.
> Используйте бота на свой риск.

## Установка

1. Установите [Python 3.11+](https://www.python.org/downloads/) и при установке
   отметьте **Add Python to PATH**.
2. Запустите `start.bat`. При первом запуске он сам установит `vgamepad`.
   Если откроется установщик драйвера виртуального геймпада ViGEmBus — согласитесь.
   Вручную то же самое делается командой в папке бота:
   ```
   python -m pip install -r requirements.txt
   ```
   Для управления с клавиатуры `vgamepad` не нужен: достаточно указать
   `input = "keyboard"` в `config.toml`.

## Запуск

```
python afk_bot.py              # или двойной клик по start.bat
python afk_bot.py --dry-run    # ничего не нажимает, только показывает шаги — для проверки
python afk_bot.py --input keyboard
```

После запуска бот ничего не нажимает и ждёт. Перейдите в игру, откройте экран
старта заезда (где кнопка «Начать») и нажмите **F8**. Со стандартным сценарием
бот сам нажмёт «Начать», переждёт отсчёт 3-2-1 и поедет.
Если хотите, чтобы он стартовал без F8, поставьте `start_paused = false`
и `start_delay = 5` — этого хватит, чтобы переключиться в игру.

## Настройка под свой заезд

Готового сценария «на все случаи» нет: длина гонки и экраны после финиша
зависят от трассы и режима. Настройка занимает один заезд.

1. Выберите трассу, где машина едет сама с зажатым газом. Обычно это
   пользовательские AFK-трассы, их ищут по словам «AFK», «XP» или «skill points».
2. Пройдите один заезд вручную с секундомером и запишите:
   - сколько длится гонка от старта до финиша;
   - какие кнопки и сколько раз вы нажимали после финиша, чтобы перезапустить
     заезд (например «A, A, A, потом вниз, потом A»);
   - сколько грузится новый заезд.
3. Перенесите это в шаги `[[cycle]]` в `config.toml`:
   - `drive` → `duration` — длина гонки плюс 10–20 секунд запаса;
   - если машину уводит в сторону, добавьте лёгкий руль, например `steer = 0.1`;
   - каждый пункт меню — отдельный шаг `press`. Для навигации есть `DPAD_UP`
     и `DPAD_DOWN`, для подтверждения — `A`.
4. Запустите `python afk_bot.py --dry-run` и сверьте шаги со своими записями.
   Потом запускайте по-настоящему и понаблюдайте за первыми двумя-тремя циклами.

Пример: после финиша нужно трижды нажать A, затем выбрать второй пункт меню
«Перезапустить»:

```toml
[[cycle]]
action = "press"     # «Начать»
button = "A"

[[cycle]]
action = "wait"      # отсчёт 3-2-1
duration = 3

[[cycle]]
action = "drive"
throttle = 1.0
duration = 320

[[cycle]]
action = "press"
button = "A"
count = 3
interval = 2.5

[[cycle]]
action = "press"
button = "DPAD_DOWN"

[[cycle]]
action = "press"
button = "A"

[[cycle]]
action = "wait"
duration = 15
```

## Если что-то не работает

- **Игра не реагирует на бота.** Если игра запущена от имени администратора,
  запустите от администратора и бота: Windows не даёт обычной программе
  нажимать кнопки в окне администратора. Ещё можно попробовать другой способ
  ввода: `input = "keyboard"` вместо `"gamepad"` или наоборот.
- **С клавиатуры нажимаются не те действия.** Сверьте раздел `[keyboard]`
  с управлением в настройках игры.
- **Бот пишет «окно игры не активно», хотя игра открыта.** Посмотрите точный
  заголовок окна игры и поправьте `window_title`. Проверку окна можно и
  выключить: `require_focus = false`.
- **Бот остановился, пока компьютер был без присмотра.** Отключите сон
  и гибернацию в настройках электропитания Windows.
